## 🧱 Data Structures vs 🗄️ Database

They are related, but they are **not the same thing**.

| Data Structure 🧱                                       | Database 🗄️                                                     |
| ------------------------------------------------------- | ---------------------------------------------------------------- |
| Organizes data **inside a program**                     | Stores and manages **large amounts of data**                     |
| Usually works in memory while the program is running 🧠 | Usually stores data permanently on disk 💾                       |
| Examples: Array, Stack, Queue, Tree                     | Examples: MySQL, PostgreSQL, MongoDB                             |
| Focuses on **how data is organized**                    | Focuses on **storing, searching, updating, and protecting data** |
| Often used by programmers inside code 👨‍💻             | Used by applications to keep information for a long time         |

### 🌟 Simple example

Imagine a school system 🏫.

A **data structure** might temporarily hold student names while the program is running:

```text
[Ali, Sara, Omar, Lina]
```

A **database** stores all student information permanently:

```text
Name: Ali
Age: 20
Grade: 85
Email: ali@email.com
```

Even if you close the program ❌💻, the database usually keeps the information.

### 🧠 Easy way to remember

**Data Structure = How data is organized inside the program.** 🧱

**Database = Where large amounts of data are stored and managed for long-term use.** 🗄️

A program can also use **data structures and a database together**. The database stores the information, and the program may load some of that information into arrays, lists, trees, or other data structures to work with it efficiently.
