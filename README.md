# Data Structures — C++

A learning repository of **notes and C++ examples about data structures and algorithmic complexity**.

## Topics

Explore [Data Structures — Level 1](Data%20Structures%20-%20Level%201):

- **Fundamentals:** what data structures are, classifications, and how they differ from databases
- **Big O:** time and space complexity, including constant, linear, quadratic, and logarithmic examples
- **Linear structures:** arrays, vectors, stacks, and queues
- **Linked lists:** singly and doubly linked lists, with insertion, searching, and deletion
- **Other concepts:** abstract data types (ADTs), maps, and unions

The folders contain Markdown explanations (`.md`) and working examples to explore (`.cpp`).

## C++ Naming Convention

- **Class** → `PascalCase`
- **Function** → `camelCase`
- **Variable** → `camelCase`
- **Constant** → `SCREAMING_SNAKE_CASE`
- **Boolean** → `isSomething` / `hasSomething` / `canSomething`

## How to Use

Read a lesson's Markdown notes, then examine the related C++ code to understand the implementation. Topics are separated for easy review.

## Goal

Develop an understanding of **how structures work, how to implement them, and how to reason about performance**.
