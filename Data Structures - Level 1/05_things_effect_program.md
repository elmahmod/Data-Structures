## ⚡ Things That Affect Program Speed & Efficiency

A program can be **fast or slow** depending on several things.

### 1️⃣ Algorithm 🧠

An **algorithm** is the set of steps used to solve a problem.

A good algorithm uses fewer steps ✅
A bad algorithm may use too many steps ❌

Example:

```text
Find a name in 1,000 students
```

One method may check every student one by one 🐢, while another method may find the student much faster ⚡.

---

### 2️⃣ Data Structure 📦

The way data is organized can greatly affect speed.

For example:

```text
Array
Linked List
Stack
Queue
Tree
Hash Table
```

Different data structures are better for different tasks.

For example:

* **Array** → good for quickly accessing an item by position
* **Hash Table** → often very fast for searching by key
* **Tree** → useful for organized and hierarchical data

📌 Choosing the correct data structure can make a program much faster.

---

### 3️⃣ Size of the Input 📊

A program usually takes more time when it has more data to process.

Example:

```text
10 students      → Fast ⚡
1,000 students   → More work
1,000,000 students → Much more work 🐢
```

So we study how the program behaves when the amount of data becomes larger.

---

### 4️⃣ Memory Usage 🧠💾

Programs need memory to store data.

If a program uses too much memory, it may become slower.

Efficient programs try to use:

```text
Less time ⏱️
Less memory 💾
```

---

### 5️⃣ Hardware 💻

The computer itself also affects performance.

Examples:

* ⚙️ CPU speed
* 🧠 RAM
* 💾 SSD or hard drive
* 🎮 GPU

A faster computer can usually run a program faster.

---

### 6️⃣ Programming Language and Compiler 👨‍💻

Different programming languages can have different performance.

Also, a good **compiler** can optimize the program and make it faster.

---

## 🧠 The Most Important Idea

When studying **Data Structures and Algorithms**, we mainly focus on:

> ⚡ **Time Efficiency** → How fast does the program run?

and

> 💾 **Space Efficiency** → How much memory does the program use?

### ✅ Easy Summary

```text
Program Efficiency
       │
       ├── 🧠 Algorithm
       ├── 📦 Data Structure
       ├── 📊 Input Size
       ├── 💾 Memory Usage
       ├── 💻 Hardware
       └── 👨‍💻 Programming Language
```

So, **choosing a good algorithm + the right data structure** is one of the most important ways to make a program fast and efficient.
