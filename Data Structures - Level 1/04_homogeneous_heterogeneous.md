## 📌 Important Point about Data Structures

Data Structures emphasize the **organization of a group of data items**.

The data can be:

* **Homogeneous data** → data of the **same type**
* **Heterogeneous data** → data of **different types**

### 🟢 Homogeneous Data — Same Type

All items have the same data type.

Example:

```text
[10, 20, 30, 40]
```

All values are **Integers** 🔢

Another example:

```text
["Ali", "Sara", "Omar"]
```

All values are **Strings** 🔤

📌 An **Array** often stores homogeneous data.

### 🔵 Heterogeneous Data — Different Types

The data contains different data types.

Example:

```text
Name   = "Ali"   → String
Age    = 20      → Integer
Grade  = 85.5    → Float
Passed = True    → Boolean
```

Here, the data contains different types.

### 🧠 Easy way to remember

**Homogeneous = Same type ✅**

```text
Integer + Integer + Integer
```

**Heterogeneous = Different types 🔀**

```text
String + Integer + Float + Boolean
```

### ✅ Simple definition

> **A Data Structure is a way of organizing and storing a group of homogeneous or heterogeneous data items so they can be used efficiently.**
