### 🔗 What is a Linked List?

A **Linked List** is a linear data structure made of connected **nodes**.

Each node usually has two parts:

- 📦 **Data** → stores the value.
- 👉 **Next** → stores the address of the next node.

Example:

`Head → [1 | Next] → [2 | Next] → [3 | Next] → NULL`

🟢 **Head** points to the first node.  
🔗 Each node connects to the next node using a pointer.  
🛑 **NULL** means there is no next node, so the linked list ends there.

Unlike an array, the nodes do not need to be next to each other in memory. They are connected using pointers.
